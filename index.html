¿Cómo trabajar también en Visual Studio Code?

Creá una carpeta MiPrimerJavaScript, agregá un archivo index.html, colocá el código dentro de una etiqueta <script> y abrilo en Chrome. Para ver la consola, presioná F12 y elegí Console.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primer JavaScript</title>
</head>
<body>
  <h1>Aprendiendo JavaScript</h1>
  <script>
    // Escribí aquí tu código
  </script>
</body>
</html>
